# tlk control

tlk.io 메시지와 패들렛 익명 게시를 사이트에서 설정하고 실행합니다. Node.js 22 이상이 필요합니다.

## 로컬 실행

```powershell
npm ci
npx playwright install chromium
$env:ALLOWED_ORIGINS='http://127.0.0.1:4173'
npm start
```

다른 터미널에서 `npm run preview`를 실행하고 `http://127.0.0.1:4173`을 여세요. 서버 연결 설정에 `http://127.0.0.1:3000`을 입력합니다. Linux에서는 `npx playwright install --with-deps chromium`으로 시스템 의존성도 설치합니다. Dockerfile은 Chromium과 의존성을 포함합니다.

## 패들렛 익명 게시

사이트에서 **패들렛 게시물**을 선택하고 다음 항목을 입력합니다.

- **패들렛 보드 링크**: `https://padlet.com/…` 또는 학교용 `https://….padlet.org/…`. 맞춤 링크도 허용합니다.
- **게시물 제목**: 선택 사항, 최대 200자.
- **게시물 내용**: 1~1,000자.
- **봇 수**: 각 봇이 별도의 익명 세션으로 접속합니다.
- **게시 간격**: 각 봇의 이전 게시 시작부터 다음 게시 시작까지의 초 단위 간격.
- **총 게시 수**: 모든 봇이 작성할 게시물의 합계입니다.

**자동 전송 시작**으로 실행하고 **실행 중지**로 취소합니다. 서버의 Chromium에서 게시하므로 사용자가 패들렛 탭을 직접 열 필요는 없습니다. API 키나 로그인을 사용하지 않습니다. 모니터의 `익명 봇-01` 등은 진행 상태용 이름이며 실제 보드에는 Padlet이 지정한 게스트 별칭이 표시될 수 있습니다.

소유하거나 자동 게시가 허용된 보드에서 사용하세요. 보드의 방문자 작성 권한과 익명 접속이 허용되어야 합니다. 로그인·추가 인증·전송 제한이 나타나면 중지하며 우회하거나 자동 재시도하지 않습니다. 이미 전달된 요청은 중지 후에도 완료될 수 있습니다.

표준 작성 화면의 제목·본문·게시 버튼을 사용합니다. 사용자 정의 입력 필드, 섹션 선택, 첨부파일은 지원하지 않습니다. 편집기가 닫히고 본문이 보드에 추가로 표시되어야 완료로 집계합니다. 승인 대기나 화면 변경으로 확인할 수 없으면 중지합니다. `화면확인-N`은 로컬 확인 순번이며 Padlet 게시물 ID가 아닙니다. 실제 보드에서의 호환성은 별도 확인이 필요합니다.

## 실행 조건

tlk.io와 패들렛은 실행기를 공유하므로 동시에 한 작업만 실행합니다. 모든 봇이 준비되면 첫 게시를 시작합니다. 간격은 0~3600초이며 소수도 허용합니다. 실제 속도는 브라우저 조작·응답 시간·타이머 정밀도에 따라 설정값보다 느릴 수 있습니다. 같은 봇의 요청은 중첩하지 않습니다.

봇 수와 총 전송 수는 1~9007199254740991의 정수를 받지만 실제 동시 실행 수는 서버 자원에 따라 달라집니다. 패들렛은 봇당 페이지를 사용하므로 tlk.io보다 메모리가 많이 필요합니다. 최대 실행 시간은 6시간이며 서버 재시작 시 종료됩니다. 실행기 API는 인증 없이 공유되므로 서버 URL을 아는 사람은 상태 조회·시작·중지가 가능합니다.

배포할 때 정적 화면과 실행기를 함께 업데이트하세요. 기존 API 방식 실행기는 새 익명 게시 요청과 호환되지 않습니다.

## 테스트

```powershell
npm test
# Chromium 설치 후 로컬 모의 화면에서 브라우저 테스트도 실행:
$env:BROWSER_TESTS='1'
npm test
```

기본 테스트는 설정·봇별 간격·총합 제한·중지·정리 동작을 검사합니다. 선택 브라우저 테스트는 로컬 모의 응답으로 제목/본문 입력, 중복 내용 확인, 세션 분리, 전송 제한과 확인 실패를 검사합니다. 외부 패들렛에 게시하지 않습니다.
