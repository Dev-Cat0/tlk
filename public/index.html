Instagram 프로페셔널 계정으로 보내기

먼저 DM을 보낸 상대에게 마지막 메시지 수신 후 24시간 이내에 응답할 수 있습니다. 한 계정으로 전송하며, @사용자 이름 대신 받는 사람의 IGSID가 필요합니다.

토큰은 현재 연결한 실행기 서버로 전송됩니다. 브라우저 저장소와 실행 기록에는 저장하지 않습니다.

계정과 토큰 준비하기
  1. Meta 앱에 Instagram API with Instagram Login을 설정하세요.
  2. 프로페셔널 계정으로 로그인하고 instagram_business_basic, instagram_business_manage_messages 권한을 부여하세요.
  3. 계정 ID와 액세스 토큰을 입력하세요. 받는 사람 ID는 수신 메시지 웹훅의 sender.id 또는 Conversations API에서 확인합니다.
  4. 개발 모드에서는 앱 역할·테스터 계정으로 확인하세요. 일반 사용자에게 제공하려면 필요한 앱 검토와 권한 승인을 완료하세요.
